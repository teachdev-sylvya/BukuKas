# Buku Kas Devy

Aplikasi pribadi untuk mencatat pemasukan dan pengeluaran harian (tunai, transfer bank, QRIS, e-wallet),
dengan laporan harian, mingguan, bulanan, dan tahunan, pencatatan aset, serta perkiraan zakat mal.

Data pribadi tidak disimpan di repositori ini. Data tersimpan di perangkat masing-masing,
dan (jika disambungkan) di gist privat milik akun pemilik.
